# IELTS Beta — UI Design Prototype

A 9-screen click-through UI prototype for **IELTS Beta 3.0**, an IELTS learning web app. Built as static HTML/CSS/JS — no build step, no backend, no dependencies.

## 🔗 Live preview

**[View the live prototype](https://YOUR-USERNAME.github.io/ielts-beta-ui-prototype/)** ← set up via GitHub Pages (see below)

## Screens

| # | Screen | File |
|---|--------|------|

| 02 | Sign In | `phase2-auth.html` |

| 04 | Learning | `phase4-learning.html` |
| 05 | Practice | `phase5-practice.html` |

| 07 | Rewards | `phase7-gamification.html` |
| 08 | Teacher Portal | `phase8-teacher.html` |

Start at `index.html` for a menu of every screen. Every screen also has a small floating **☰** button (bottom-right) that opens a jump-to-any-screen panel, so the whole prototype is browsable without needing to go back to the index each time.
